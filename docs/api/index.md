# API

API предоставляет доступ к функциям ИИ-сервиса AI-compact для создания и хранения кратких пересказов текста.

## Основные операции

- `POST /summaries` — создать краткий пересказ текста с помощью ИИ.
- `GET /summaries/{id}` — получить ранее созданный пересказ по его идентификатору.
- `GET /summaries/history` — получить историю пересказов пользователя.

## Спецификация

Полное описание API находится в файле [`openapi.yaml`](openapi.yaml).
