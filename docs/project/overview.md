# Сервис автоматического краткого пересказа текста

Сервис принимает большой текст и возвращает краткое содержание

Основные пользователи:
- пользователь;
- администратор;

Основные функции:
- отправка текста;
- получение краткого пересказа текста;
- просмотр истории пересказов пользователей (администратор);

## Комплект документации

1. Описание проекта - для всех участников проекта, объясняет назначение сервиса, его цели и основные функции.
2. Требования к системе - для разработчиков, описывает функциональные и нефункциональные требования к системе
3. Документация API - для разработчиков, объясняет как другие приложения могут взаимодействовать с сервисом
4. Руководство пользователя - для пользователей, объясняет как использовать сервис
5. Руководство администратора - для администраторов, описывает просмотр истории пересказов и управление работой сервиса.
