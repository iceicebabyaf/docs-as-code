### US-01. Создание краткого пересказа

Как пользователь,
я хочу отправить большой текст на обработку,
чтобы получить его краткое содержание.

Критерии приемки:
- Система принимает текст, введенный пользователем.
- После обработки система возвращает краткий пересказ текста.
- Если текст слишком длинный, система должна уведомить пользователя о превышении лимита и предложить сократить текст.

### US-02. Просмотр истории пересказов
Как пользователь,
я хочу просматривать историю своих пересказов,
чтобы иметь возможность вернуться к предыдущим результатам.

Критерии приемки:
- Система сохраняет все пересказы, выполненные пользователем.
- Пользователь может просматривать список своих пересказов.
- Если история пуста, система должна уведомить пользователя о том, что пересказы отсутствуют.

### US-03. Просмотр истории пересказов пользователей
Как админимстратор,
я хочу просматривать историю пересказов всех пользователей,
чтобы иметь возможность анализировать использование системы.

Критерии приемки:
- Администратор может просматривать список всех пересказов, выполненных пользователями.
- Для каждого пересказа отображается оригинальный текст, краткий пересказ и информация о пользователе, который его создал.
- Пользовательские данные должны быть защищены и отображаться только администратору.

### UC-01. Создание краткого пересказа текста

Актор: пользователь

Цель: получить краткое содержание большого текста с помощью искусственного интеллекта.

Предусловие: пользователь открыл сервис и подготовил текст для обработки

Основной сценарий:
1. Пользователь вводит или вставляет текст в поле ввода.
2. Пользователь запускает создание краткого пересказа.
3. Система проверяет, что текст не пустой и не превышает допустимый лимит длины.
4. Система передаёт текст ИИ-модели для обработки.
5. ИИ-модель формирует краткое содержание текста.
6. Система отображает результат пользователю.

Альтернативный сценарий:
Если текст пустой или превышает допустимый лимит, система показывает соответствующее сообщение и предлагает исправить текст.
Если при обработке возникает ошибка, система уведомляет пользователя о невозможности создать пересказ и предлагает повторить попытку.

Результат: пользователь получает краткий пересказ исходного текста либо сообщение о причине, по которой обработка не выполнена.
